# Product vision

DevRoute AI Studio is a local-first API development workspace for Windows and mobile. It starts with reliable API organization and inspection, then grows into an AI-assisted debugging, testing, and monitoring studio.

The first release foundation prioritizes clarity, safe handling of secrets, and extensibility over feature breadth.
## Current roadmap position

Phase 4 — GraphQL Studio is current and in progress. Phase 1, Phase 2, and Phase 3 are complete; gRPC and later protocol/team work remain deferred.
