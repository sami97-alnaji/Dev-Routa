# Feature roadmap

1. **Foundation:** documentation, models, contracts, schema draft, routes, theme, adaptive shells.
2. **Core API workflow (Phase 2):** local schema migration, secure secret references, Cubit request flow, REST execution, safe response/history tooling, and local CRUD repository groundwork.
3. **Developer intelligence:** WebSocket client, history tools, consent-based AI analysis.
4. **Expansion:** SSE, GraphQL, gRPC, optional sync and teams after product validation.
