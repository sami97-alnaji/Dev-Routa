# UI and UX structure

Desktop uses a persistent rail with workspace, request, history, environments, AI tools, and settings. The request workspace contains method/URL controls and an expandable response area.

Mobile uses a compact bottom navigation and focused screens rather than a compressed desktop workspace. The foundation uses simple Material surfaces and no decorative animations.

Phase 2 keeps the same adaptive principle while routing the request composer through a Cubit. Sending has validation feedback, busy/cancel state, a safe response preview, and an explicit unsaved indicator.
